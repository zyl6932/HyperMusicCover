# 锁屏超级岛材质设置

锁屏超级岛、迷你播放器以及通知小岛现在可以在设置页选择四种背景模式：

| 模式 | 设置 |
| --- | --- |
| 系统自动 | 回放 SystemUI 媒体卡的原生材质；旧配置默认使用此模式。 |
| 纯色 | 输入 `#AARRGGBB` 格式的背景颜色，包含透明度。 |
| 高级材质 | 调整混色颜色、不透明度、背景模糊度和高光。 |
| 柔光玻璃 | 调整混色颜色、不透明度、背景模糊度、Glass 模糊度和柔光强度。 |

手电筒和相机快捷按钮的背景默认跟随锁屏岛。关闭“跟随锁屏岛材质”后，两个按钮共用一份独立的快捷背景配置。背景和 Glass 模糊度范围均为 0–40；柔光强度为 0–0.4。

这些设置与原有尺寸参数一起存入 `minicfg`，随现有广播和设置备份导入导出。旧版配置在读取时补齐默认值。系统自动模式继续使用原有媒体卡材质记录与回放；自定义模式通过 HyperOS 的 View 模糊和 MiGlass 接口绘制。切换模式时重建材质图层并清除旧容器模糊状态。若厂商接口不可用，自定义模式以所选颜色填充并记一次日志。

本功能的材质参数与 Xiaomi API 调用参考 HyperChanger 1.1.3；来源与许可见项目 `NOTICE`。实际模糊效果需要在支持这些接口的 HyperOS 设备上验证。
