# 卡片样式动态流光背景

此功能仅在音乐锁屏的卡片样式开启。默认保持原静态模糊背景；切换到完整封面样式会保留流光设置，但不显示动态层。

`CoverCardLayer` 在现有封面准备线程生成 128×128 的缩图，并在静态壁纸开始换曲时把缩图交给 `CoverFlowRuntime`。后者将 Kawarp-AGSL 的取色、着色和 Kawase 模糊放在后台线程，屏幕可见时以 Android `RuntimeShader` 绘制流动颜色。首次着色尚未完成、AGSL 不可用或绘制失败时，透明动态层会露出原静态壁纸。动态层位于快捷方式圆盘背景、卡片封面、歌词和锁屏根层之下；换曲交叉淡化时长与封面一致，为 180 毫秒。

流光透明度跟随音乐锁屏卡片进入、退出进度；首次着色延迟完成时从透明状态在 220 毫秒内渐显。锁屏歌词页继续显示同一流光，并随歌词出现进度叠加最多 40% 的黑色压暗。息屏时沿用卡片的明暗过渡，进入 AOD 后停止逐帧绘制。视频壁纸路径保留原静态封面底图，按流光透明度逐步让出画面；软件画布截图不会使硬件着色器进入失败状态。

设置包括三档预设及强度、速度、模糊次数。预设选择重置三项参数，后续手动调节会保存；模糊次数在拖动结束时才发给 SystemUI 重新处理当前封面。暂停播放后流速逐渐降为零。设置由现有 SystemUI 广播、状态文件和备份链路传递；旧配置缺少流光字段时默认为关闭。

渲染引擎源码来自 [Kawarp-AGSL](https://github.com/meowarex/kawarp-agsl)，许可证为 LGPL-3.0；其衍生的原版 [Kawarp](https://github.com/better-lyrics/kawarp) 设计与着色器代码为 MIT 许可。完整声明见 [`third_party/kawarp-agsl`](../third_party/kawarp-agsl/) 与根目录 `NOTICE`。引擎通过 Android API 33 提供的 `RuntimeShader` 工作；项目最低系统版本为 API 35。

此层实现的是卡片后方可见的动态颜色。HyperOS 原生玻璃组件可能仍从底层静态壁纸采样模糊；普通构建和模拟器无法证实目标设备上的最终合成效果。

## 媒体卡与通知卡同步背景（0.5.1-custom.7）

原版封面通过壁纸进程替换纹理，原生卡片可以从壁纸表面取样；流光是 SystemUI 内的 AGSL View，原生取样仍可能得到它下方的静态壁纸。现在锁屏中展开的媒体卡 `media_bg` 和通知行背景各有一个独立的 AGSL 绘制层，使用根流光在同一帧发布的封面、动画时间和换曲混合值。卡片的 View 变换映射到流光根层坐标，拖动或形变时图案不会以卡片自身为原点重新开始。没有逐帧截图或位图上传。

叠层最高 65% 不透明度；原生玻璃材质、圆角和前景内容仍由系统绘制。它随流光进入、退出及歌词压暗变化，关闭设置、AOD、解锁或卡片脱离时移除。通知背景在某个 HyperOS 版本上无法定位时，该通知保留原生背景并记录一次诊断。此方案不改变壁纸进程，也不改变迷你岛、通知岛或快捷按钮的材质设置。目标设备仍需检查玻璃层与 AGSL 的实际合成顺序和文字对比。

## 根层变黑修复（0.5.1-custom.8）

`custom.7` 将根流光和卡片绘制统一到带 `shade` 参数的绘制器，根层的两条调用路径误传入 `1f`，使 AGSL 颜色乘以零。卡片有独立绘制器，所以卡片内部流光仍正常。根层现通过专用入口固定使用恒等坐标映射和零着色器压暗；锁屏歌词所需的最多 40% 压暗仍由根层 View 在着色器绘制之后叠加，卡片则沿用各自的歌词压暗值。
